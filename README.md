One-line voicemail greeting entry for the make.fun bounty
[Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

`main.py` (Python 3 stdlib only) writes a single cat-recorded voicemail
greeting to `/output/entry.txt` — 99 characters, one line, UTF-8, no
trailing newline.

## Files

- `main.py` — the entry (stdlib-only copier)
- `README.md` — this file
- `LICENSE` — MIT

## Run

```sh
python3 -P -s main.py
```
